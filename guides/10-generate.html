Step 10 — Generate, install and check (wizard steps 10 and 11)

Generation (step 10)

  1. The Checks list must be green: world closed in Minecraft, structure and samples ready, place (in the game with the wand, or position confirmed).

    The pack name gives the name of the song in the game: “Miss You” → /function music:miss_you/….

  2. Packs and options — pack name, description, version, icon.
  3. Click Generate and install in the world….
  4. A confirmation window lists exactly what will happen: files written, size of the structure, other songs of the world, world backup. Confirm.
  5. The software makes a ZIP backup of the world, then installs:
    • the song's datapack in datapacks/music_<name>.zip;
    • its sounds in mmstudio_packs/<name>.zip;
    • the world's resource pack (resources.zip in 1.21, resourcepacks/resources.zip in 26.x), which gathers the sounds of all the songs installed in that world: Minecraft loads it automatically when the world opens, and only in that world.

To put several songs in the same world (full edition; the free edition keeps a single one), generate and install each project one after the other: the songs already installed are kept (the Songs installed in this world line lists them). Remove a song from the world… takes its datapack and its sounds out (they are moved to the backups); remove its structure in the game first with /function music:<name>/remove.

No file is ever deleted: a replaced file is moved into the backup folder.

Generate the files only writes nothing into the world (for a server or a manual installation).

Check (step 11)

Click Check: the files are re-read exactly as the game will read them (every sound event exists and is a valid OGG Vorbis file, every sound used by the datapack is in the resource pack, the installed datapack is identical and the world pack holds the song's sounds).
