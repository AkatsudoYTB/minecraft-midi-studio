Règles de confidentialité

Dernière mise à jour : 11 octobre 2026.

Minecraft MIDI Studio est un programme qui fonctionne sur votre ordinateur. Son auteur n'a aucun serveur et ne collecte aucune donnée : ni statistiques, ni publicité, ni suivi.

Vos fichiers

Vos fichiers MIDI, vos projets et vos mondes Minecraft restent sur votre ordinateur. Le programme les lit et n'écrit que là où vous le confirmez (installation dans un monde, avec une sauvegarde avant). Rien n'est envoyé.

Sons officiels de Minecraft

Quand aucune installation de Minecraft de votre ordinateur n'a les fichiers nécessaires, le programme télécharge les sons et les textures officiels depuis les serveurs de Mojang (piston-meta.mojang.com, resources.download.minecraft.net), comme un launcher. Seules ces demandes de téléchargement sont faites ; comme pour tout téléchargement, Mojang reçoit votre adresse IP (voir la déclaration de confidentialité de Microsoft).

Connexion Google (édition complète)

Seulement quand vous cliquez sur Activer avec Google ou Récupérer ma licence avec Google, vous vous connectez sur la page de Google, dans votre navigateur. Le programme ne voit jamais votre mot de passe. Il reçoit :

  • votre adresse e-mail, pour vérifier que la clé de licence a été achetée pour ce compte ;
  • l'accès au dossier caché « données d'application » de votre Google Drive réservé à ce programme (accès drive.appdata), où il range un seul fichier : votre clé de licence. Il ne peut pas voir vos autres fichiers.

Cet accès est utilisé tout de suite et n'est pas conservé. Votre adresse e-mail est enregistrée seulement sur votre ordinateur, dans le fichier d'activation chiffré. L'utilisation et le transfert des informations reçues des API Google par Minecraft MIDI Studio respectent les règles relatives aux données utilisateur des services d'API Google, y compris les exigences d'utilisation limitée.

Supprimer vos données

  • Sur votre ordinateur : Licence → Retirer la licence de cet ordinateur, puis supprimez les dossiers indiqués dans le guide d'installation.
  • Dans Google Drive : Paramètres → Gérer les applications → Minecraft MIDI Studio → Options → Supprimer les données d'application cachées. Vous pouvez aussi retirer l'accès du programme sur myaccount.google.com/permissions.

Achats

Les paiements sont traités par la boutique (Ko-fi et ses prestataires de paiement), selon leurs propres règles de confidentialité. L'auteur garde le nom, l'adresse e-mail et l'adresse Google d'un acheteur seulement pour créer la clé de licence et la renvoyer si besoin.
