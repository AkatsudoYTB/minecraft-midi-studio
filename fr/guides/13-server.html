Étape 13 — Jouer sur un serveur

Objectif : utiliser la musique sur un serveur multijoueur (édition complète).

  1. À l'étape 11, cliquez sur Exporter pour un serveur… et choisissez un dossier. Vous obtenez :
    • music_mmstudio.zip (le datapack) ;
    • le resource pack (.zip) ;
    • LISEZ-MOI-SERVEUR.txt : les instructions, avec le SHA-1 du pack.
  2. Datapack : copiez music_mmstudio.zip dans <monde du serveur>/datapacks/, puis tapez /reload (ou redémarrez le serveur).
  3. Resource pack : mettez le resource pack à une adresse de téléchargement directe (HTTP ou HTTPS), puis dans server.properties :
    resource-pack=<adresse du fichier>
resource-pack-sha1=<SHA-1 donné dans les instructions>
require-resource-pack=true   (facultatif)
  1. Pour la console de boutons : enable-command-block=true dans server.properties.
  2. En jeu, en opérateur : /function music:build, puis /function music:play.

Les joueurs non opérateurs contrôlent la musique avec /trigger music.play, /trigger music.volume set 150, etc.

Les sons du pack sont ceux de Minecraft (ils appartiennent à Mojang) : utilisez-les pour votre serveur, mais ne publiez pas le pack.
