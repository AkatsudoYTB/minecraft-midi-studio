Étape 13 — Jouer sur un serveur

Objectif : utiliser la musique sur un serveur multijoueur (édition complète).

  1. À l'étape 11, cliquez sur Exporter pour un serveur… et choisissez un dossier. Vous obtenez :
    • music_<nom>.zip (le datapack de la musique) ;
    • le resource pack (.zip) ;
    • LISEZ-MOI-SERVEUR.txt : les instructions, avec le SHA-1 du pack.
  2. Datapack : copiez music_<nom>.zip dans <monde du serveur>/datapacks/, puis tapez /reload (ou redémarrez le serveur).
  3. Resource pack : mettez le resource pack à une adresse de téléchargement directe (HTTP ou HTTPS), puis dans server.properties :
    resource-pack=<adresse du fichier>
resource-pack-sha1=<SHA-1 donné dans les instructions>
require-resource-pack=true   (facultatif)
  1. Pour la console de boutons : enable-command-block=true dans server.properties.
  2. En jeu, en opérateur : /function music:<nom>/wand pour la baguette de placement (clic droit sur un bloc = coin avant gauche de la structure, zone en bleu), puis /function music:<nom>/build et /function music:<nom>/play. Avec des coordonnées fixes choisies dans le logiciel, la baguette est inutile.

Les joueurs non opérateurs contrôlent la musique avec /trigger music.<nom>.play, /trigger music.<nom>.volume set 150, etc.

Plusieurs musiques sur le serveur : copiez chaque datapack dans datapacks/. Le serveur n'accepte qu'un resource pack : installez les musiques dans un monde avec le logiciel (étape 10), puis hébergez le resources.zip de ce monde, qui contient les sons de toutes (son SHA-1 se calcule par exemple avec certutil -hashfile resources.zip SHA1).

Les sons du pack sont ceux de Minecraft (ils appartiennent à Mojang) : utilisez-les pour votre serveur, mais ne publiez pas le pack.
